# Playwright Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Selenium WebDriver backend in `osf/cli.py` with Playwright (sync API, Microsoft Edge channel) while preserving the existing CLI surface, JSONL/webhook output, and process-tree cleanup guarantees.

**Architecture:** Swap the two driver-related functions in `osf/cli.py` (`build_driver`, `close_driver`) for Playwright equivalents (`build_browser`, `close_browser`). Use `sync_playwright()` as a context manager and `chromium.launch(channel="msedge", ...)` to drive the system-installed Edge. Keep the existing `psutil` process-tree walk and the existing `tempfile.mkdtemp` user-data-dir pattern. Update packaging metadata and README. Verify with four manual smoke tests.

**Tech Stack:** Python 3.10+, Playwright sync API, `psutil`, `requests`, `setuptools`.

## Global Constraints

- Workspace is **not** a git repository; "commit" steps are recorded as `git`-style notes but no actual commit is performed. A short summary file is updated instead.
- Python `>=3.10` is required (matches `pyproject.toml`).
- Microsoft Edge is the required browser (Playwright `channel="msedge"`); Google Chrome is not used.
- No `playwright install` step is run; the tool reuses the installed Edge.
- The CLI surface (`-t`, `-i`, `--output`, `--webhook-url`, `--webhook-timeout`, `--visible`, `--no-print-first`) and the price-change detection / JSONL / webhook payload schema are unchanged.
- The 5-second warm-up after `goto` and the sub-millisecond poll cadence are preserved (`Locator.inner_text(timeout=0)`).
- `psutil` cleanup pattern stays: collect child PIDs from the browser process, terminate, force-kill survivors after 3 seconds, then remove the user-data-dir.
- Process name match list in cleanup includes `msedge.exe` and `msedgewebview2.exe` (Edge on Windows uses a WebView2 helper process).
- The `openstockfeed.egg-info/requires.txt` file is regenerated by `pip install -e .`, not edited by hand.
- Webhook requests keep their existing `except Exception: pass` swallow; price printing is unaffected by webhook failure.

```python
def build_browser(headless: bool):
    user_data_dir = tempfile.mkdtemp(prefix="osf_edge_profile_")
    user_agent = (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/126.0 Safari/537.36"
    )
    launch_args = [
        "--disable-blink-features=AutomationControlled",
        "--no-sandbox",
        "--disable-dev-shm-usage",
        "--disable-gpu",
        "--window-size=1400,1000",
    ]

    playwright = sync_playwright().start()
    msedge_pid = None
    tracked_pids = set()
    browser = None

    try:
        browser = playwright.chromium.launch(
            channel="msedge",
            headless=headless,
            args=launch_args,
        )
        context = browser.new_context(user_agent=user_agent)
        page = context.new_page()

        try:
            msedge_pid = browser.process.pid
            tracked_pids = get_process_tree_pids(msedge_pid)
        except Exception:
            pass

    except PlaywrightError as exc:
        try:
            shutil.rmtree(user_data_dir, ignore_errors=True)
        finally:
            playwright.stop()
        raise SystemExit(
            "Error: Microsoft Edge is required. "
            "Install from https://www.microsoft.com/edge and try again."
        ) from exc

    return playwright, browser, page, msedge_pid, tracked_pids, user_data_dir
```

```python
def close_driver(driver, chromedriver_pid: int | None, tracked_pids: set[int], user_data_dir: str | None) -> None:
    print("Closing Selenium Chrome session...", flush=True)

    if chromedriver_pid:
        tracked_pids.update(get_process_tree_pids(chromedriver_pid))

    if driver is not None:
        try:
            tracked_pids.update(get_process_tree_pids(driver.service.process.pid))
        except Exception:
            pass

        try:
            driver.close()
        except Exception:
            pass

        try:
            driver.quit()
        except Exception:
            pass

    time.sleep(1)

    still_alive = set()

    for pid in tracked_pids:
        try:
            if psutil.pid_exists(pid):
                process = psutil.Process(pid)
                name = process.name().lower()

                if "chrome" in name or "chromedriver" in name:
                    still_alive.add(pid)

            pass

    if still_alive:
        kill_pids(still_alive)

    if user_data_dir:
```
